Chicken Bookmarklet

Drag this link to your bookmarks bar, then click it on any page to inject the chicken.

🐔 Chicken

Click the bookmark again on the same page to remove the chicken.

Setup

  1. Host game/public (e.g. npm start or any static server).
  2. Rebuild with your host URL: node scripts/build-bookmarklet.js --base-url http://localhost:3000
  3. Drag the bookmark link above into your bookmarks bar.

Assets

  • Widget: http://localhost:3000/src/chicken-widget.js
  • Script: http://localhost:3000/chicken-bookmarklet.js
  • Sprite: http://localhost:3000/sprites/chicken/chicken-sprite.png
